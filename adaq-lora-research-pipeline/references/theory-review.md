## 1. 审查对象与数学框架

手册 v3.0 的理论体系由四层构成：

- **误差模型**：Ŵ_l = Q₄(W_l) = W_l + E_l，NF4 分块量化，‖E_l‖_F ≤ ε₄‖W_l‖_F（ε₄≈0.02，经验值）
- **逼近目标**：B_l A_l ≈ ΔW*_l − E_l（量化误差被视为已知固定偏移，这是全文最关键的洞察，本身成立）
- **最优分配**：拉格朗日边际条件 σ_{l,r_l+1}² = λ（定理 2）
- **可实现公式**：r_l ∝ ‖E_l‖_F · I_l（启发式代理，方案 A/B/C）

审查顺序必须自底向上：先误差模型，再逼近目标，再最优性定理，最后代理公式。上层结论依赖下层假设，下层出错则上层全部重查。

## 2. 理论审查清单

### A. 量化误差模型
- [ ] A1 NF4 零均值假设 𝔼[E_l]=0 是否成立？分块 absmax 量化对正/负值非对称处理时零均值仅近似成立——论文中必须写"近似零均值"，并用实测直方图支撑。
- [ ] A2 ε₄≈0.02 必须在自己用的模型（Llama-3-8B 等）上实测确认，附表报告每层 ε_l 的分布（min/median/max），不能直接引用经验值。
- [ ] A3 "块内同分布、块间独立"：NF4 块大小 64，该假设用于谱分析时是理想化，需在假设部分明确声明。

### B. 低秩逼近与 Eckart-Young
- [ ] B1 ℰ_l(r_l) = Σ_{i>r_l} σ²_{l,i} 的应用正确（Eckart-Young-Mirsky），但注意它要求目标矩阵 ΔW*_l − E_l 的奇异值真实存在且未知——论文中所有用到 ΔW*_l 谱的地方都要标注"存在但不可观测"。
- [ ] B2 拉格朗日对整数变量 r_l 求偏导是连续松弛，必须写明"松弛到连续域求解，再取整"，并在 R ≫ L 时论证取整损失可忽略。

### C. 定理核验（详见 §3）
- [ ] C1 定理 1 的不等式方向与常数因子
- [ ] C2 定理 2 的适用前提（凸性/连续松弛）
- [ ] C3 定理 3 的界是否有完整证明

### D. 可实现公式与代理指标
- [ ] D1 r_l ∝ ‖E_l‖_F·I_l 只能以启发式/算法设计呈现，禁止写成"最优分配公式"。
- [ ] D2 方案 A（‖W_l‖_F 作重要性）的任务无关性必须在 Limitations 讨论。
- [ ] D3 r_min=4 / r_max=128 的截断会破坏精确比例，需说明截断后重新归一化。

## 3. 已知高风险点深度分析与修复方案

### 风险点 1：定理 1 的不等式混用（最严重）

手册原文：σ_i(M) ≥ σ_i(ΔW*) − ‖E‖_F/√i，证明中先写 Weyl：σ_i(M) ≥ σ_i(ΔW*) − σ_1(E)，再写 σ_1(E) ≤ ‖E‖_F。

**问题**：
- 由 Weyl 严格成立的只是 σ_i(M) ≥ σ_i(ΔW*) − σ_1(E)。把 σ_1(E) 换成上界 ‖E‖_F 后，结论应**变弱**为 σ_i(M) ≥ σ_i(ΔW*) − ‖E‖_F，而不是手册中带 1/√i 因子的更强式。1/√i 这一项来自"随机扰动 σ_1(E)≈‖E‖_F/√min(d,k)"的启发式，且 √i ≠ √min(d,k)，两者被拼接了——这是逻辑错误。
- 更根本的：该下界允许 σ_i(M) < σ_i(ΔW*)，即严格意义上 Weyl 给出的是双向扰动界 |σ_i(M)−σ_i(ΔW*)| ≤ σ_1(E)。"谱抬升"（elevation）是期望意义上的平均现象，不是逐奇异值定理。

**修复方案（论文采用）**：
> 定理 1（双向扰动界，严格）：|σ_i(ΔW*−E) − σ_i(ΔW*)| ≤ σ_1(E) ≤ ‖E‖_F。（Weyl，严格成立）
> 命题 1'（平均谱抬升，带假设）：若 E 近似各向同性随机扰动，则 𝔼‖ΔW*−E‖_F² = ‖ΔW*‖_F² + ‖E‖_F²（交叉项期望为零），即量化误差平均而言抬升了目标矩阵的总能量与有效秩。有效秩 erank(M)=‖M‖_F²/‖M‖₂² 随 ‖E‖_F 增大而增大（在 ‖M‖₂ 变化可忽略时）。
> 并配一个数值验证图：对随机合成的 ΔW*（幂律谱）叠加不同强度的 E，画出有效秩随 ‖E‖_F 的上升曲线。这样"需要更大秩"的结论从"伪定理"变成"命题+实验证据"，审稿人无法攻击。

### 风险点 2：从边际条件到比例分配的跳跃

定理 2 给出最优性必要条件 σ_{l,r_l+1}² = λ，但手册的 boxed 公式 r_l ∝ ‖E_l‖_F·I_l **并不是**该条件的解。只有当各层奇异值谱服从相同形状的衰减律（如幂律 σ_{l,i} = c_l·i^{−α}，α 各层相同）时，最优分配才正比于 c_l^{1/α} 型表达式；"噪声底板"模型 σ_eff ≈ √(σ² + ‖E‖²_F/min(d,k)) 也只能在额外假设下推出近似比例关系。

**修复方案**：
- 论文中明确写出完整推导链：假设 H1（各层谱幂律衰减且指数相近）→ 边际条件 → r*_l ∝ 层尺度因子的幂 → 用 ‖E_l‖_F·I_l 代理该因子。
- 将 boxed 公式降级为"分配规则（Allocation Rule）"，定位为"在 H1 下对最优解的可计算代理"，而非"最优分配公式"。
- 消融实验（仅误差/仅重要性/乘积/均匀）正是为这个代理的有效性提供证据——写作时点明这一对应关系。

### 风险点 3：定理 3 的 O(L/R) 界无证明

"代理单调正相关"得不出 O(L/R) 的误差界；该界看起来是整数取整误差的量级（L 层各损失至多 ~1 个秩单位，总量 R），与代理误差无关。

**修复方案**：拆成两条诚实表述：
> 命题 3a（取整损失）：连续最优解取整引起的总误差损失 ≤ O(L·σ̄²/R) 量级（σ̄ 为边际谱平均），R ≫ L 时可忽略。——这可严格证。
> 命题 3b（代理质量，经验性）：代理与真实边际奇异值的相关性用 Spearman 相关系数在实验中报告（预计算脚本可直接输出）。≥0.7 即可声明"代理有效"，不必声称近似最优性界。

### 风险点 4：NF4 假设边界

- NF4 是分位数量化，对近似正态的权重最优；对含离群通道的层（如 Llama 部分 down_proj），ε_l 显著偏大——这恰好支撑 AdaQ-LoRA 的层间异质性动机，应作为正面证据展示（逐层 ε_l 分布图），而不是藏在假设里。
- 双重量化（double quant）只作用于量化常数，不改变 E_l 的定义，但反量化时必须用与训练一致的反量化路径，否则预计算的 ‖E_l‖_F 与训练实际不符（见 training-optimization.md §5）。

### 风险点 5：E_l 已知性的论证

"E_l 已知且固定"成立的前提是量化在训练全程冻结（QLoRA 满足）。若未来扩展到量化参数联合训练（如 LoftQ/QA-LoRA 变体），E_l 变为可学习，整个"已知偏移"框架失效——Related Work 中应主动划清这条边界，既防审稿人质疑，又自然引出 future work。

## 4. 表述分级规则

| 层级 | 标注词 | 要求 | 手册中对应内容 |
| :--- | :--- | :--- | :--- |
| 严格定理 | Theorem | 完整证明，无隐藏假设 | Eckart-Young 分解（B1）、修复后的双向扰动界 |
| 命题 | Proposition | 证明概要+显式假设 | 边际条件（连续松弛下）、平均谱抬升、取整损失 |
| 启发式 | Heuristic / Design choice | 仅需实验证据 | r_l ∝ ‖E_l‖_F·I_l、I_l=‖W_l‖_F、r_min/r_max |
| 经验值 | Empirical | 必须实测复核 | ε₄≈0.02、预期提升幅度 |

升格（把启发式写成定理）是 Q2+ 审稿的拒稿级错误；降级不会丢分，反而因诚实性加分。
