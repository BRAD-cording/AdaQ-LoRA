# Paper: Error-Aware Rank Allocation Collapses to Norm-Aware Allocation in 4–8-Bit LoRA

Manuscript sources and the scripts that regenerate every number in the tables.
Target venue: *Neurocomputing* (Elsevier). Current build: 14 pages.

## Contents

| File | Purpose |
|---|---|
| `neurocomputing_paper.tex` | manuscript source (elsarticle, `preprint` option) |
| `references.bib` | bibliography; every entry was checked against the arXiv API or Crossref |
| `recompute_stats.py` | regenerates **Table 1** (six quantizer × benchmark cells): paired *t*, 95% CI, Cohen's *d*, Benjamini–Hochberg *q*, MDE₈₀, TOST sample sizes |
| `rtn_b16_gsm8k.csv` | per-seed GSM8K strict-match scores of the INT4-RTN runs under the uniform protocol (5-shot, batch 16, 12 seeds) |
| `analyze_b16.py` | patch-in of the 12-seed INT4-RTN cell and the flexible-extract robustness check |
| `gen_figure.py` | programmatically redraws Fig. 1 (audit protocol schematic) with Pillow |

## Regenerating the numbers

```bash
python recompute_stats.py      # prints Table 1, the TOST table and the flex check
python analyze_b16.py          # prints the 12-seed cell and its equivalence bounds
```

Both scripts are pure standard library (the Student-t CDF is implemented
directly), so they run without scipy. `recompute_stats.py` reads
`rtn_b16_gsm8k.csv` (GSM8K) and `rtn_b16_mmlu.csv` (MMLU); the NF4 and INT8 cells are typed in from
`results_v2/summary.json` and `epsilon_and_tables.txt` of the experiment tree.

## Where the per-seed results live

* **INT4-RTN, uniform protocol (used in the paper)** — `results_v2_rtn_b16/`,
  one directory per `(method, seed)` with `gsm8k/results_*.json` and, for the
  three seeds used in the MMLU cell, `mmlu/results_*.json`.
* **INT4-RTN, legacy runs** — `results_v2_rtn/`. These mixed 4-shot and 5-shot
  evaluation across seeds and were therefore *not* used in the paper; they are
  kept only as the record of the original protocol drift.

Large artefacts (adapters, packed datasets, `*_samples.jsonl`) are not tracked;
see `.gitignore`.

## Figures

`gen_figure.py` reproduces Fig. 1 byte-for-byte. Fig. 2 (per-layer ε profiles) is
drawn from the epsilon reports in the experiment tree and is not regenerated by
this package; the underlying statistics are in Section 5.1 of the manuscript.
