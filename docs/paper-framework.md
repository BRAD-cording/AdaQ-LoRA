## 叙事主线

**核心论点**：量化与低秩适配的耦合被忽视。

现有 PEFT 方法（QLoRA, DoRA, AdaLoRA）在 4-bit 量化基座上微调时，对所有层分配均匀秩，**[2026-11-16 评审裁定撤回原动机]** 原文声称 NF4 层间量化误差 ε_l「可相差数倍」、「高误差层需要更大适配容量」——已被实测证伪：ε_l max/min 仅 1.0875×(8B)/1.3289×(14B)，q_proj/v_proj 均值比 0.9996/0.9997；rel_error 近常数是 NF4 per-block(64) absmax 定标 + 正态分位最优码本的**结构性后果**。score=rel_error×‖W‖_F 因此退化为 ‖W‖_F 驱动的**范数分配**（Spearman(‖W‖,score)=0.998，R²(log score, log‖W‖)=0.9995）。主张重构为「范数/重要性感知」（docs/claim-revision-norm-aware.md），本文贡献=该结构性机制的解释 + 收敛阴性结果 + 可检出效应边界。「零额外显存开销下提升参数效率」同撤：等秩下 AdaQ 参数比 QLoRA 多 +11.5%(8B)/+6.8%(14B)。

### Introduction 结构（第一段必须落在 Gap-1/Gap-2 上）

1. **背景**：4-bit 量化 + LoRA 是单卡微调大模型的标配范式（QLoRA 开创）。
2. **Gap-1**：现有方法不根据量化误差分配秩——所有层均匀分配，忽视 ε_l 异质性。
3. **Gap-2**：量化误差补偿仅做初始化（LoftQ）或幅度缩放（QA-LoRA），未做秩分配。
4. **[已撤回 2026-11-16]** Gap-3（AdaLoRA 重要性分数在量化基座不可靠）：零证据。实测三种子全部 checkpoint 的 lora_E 秩恒为 init_r=16、sum-of-ranks=1024（2× 预算）——tinit=20 > max_steps=21，剪枝从未触发，「重要性分数从未参与任何秩决定」。该 Gap 不得作为论文动机。
5. **本文方案**：AdaQ-LoRA —— 预计算 NF4 逐层误差 → 误差驱动秩分配 → 零额外开销下的参数效率提升。
6. **贡献**：(a) 量化误差驱动的分配规则；(b) 严格理论分析（扰动界+谱抬升命题+代理质量诊断）；(c) 公平对齐的实验验证。

## Limitations（5 条，每条配证据）

### L1：分配代理的任务无关性

**表述**：方案 A 使用 ‖W_l‖_F 作为任务无关的重要性代理。对于极端结构（如稀疏注意力层），该代理可能偏离真实重要性。

**证据/说明**：方案 B（逐层分配）可作为替代但失去分组效率。实验四（目标模块扩展）可提供不同模块组合下的效果差异。

### L2：幂律衰减假设 H1

**表述**：分配规则的推导依赖各层奇异值谱服从相近衰减指数的幂律分布。若实际谱衰减形态差异大，代理质量下降。

**证据/说明**：命题3b 已撤回（2026-11-16）：ρ=0.9836 为合成数据自测 ρ(score, assigned_ranks)，循环统计量。如恢复需按位点 ±4 秩扰动测 Spearman(score, −Δℓ_l)（见 review/nf4-spectral.md F 项与 review/fair-baseline.md F20）。

### L3：NF4 量化冻结假设

**表述**：E_l "已知且固定"的前提是量化在训练全程冻结。若量化参数联合训练（LoftQ/QA-LoRA 变体），框架失效。

**证据/说明**：Related Work §2.3 已划清边界。这是 future work 的自然延伸。

### L4：A10 单卡约束

**表述**：实验受限于 A10 24GB 单卡，未验证在更大模型（如 70B）上的效果。

**证据/说明**：显存预算模型（docs/training-optimization-plan.md §1）可外推；但实际效果需多卡环境验证。

### L5：分配截断的影响

**表述**：r_min=4 / r_max=128 的截断可能对极端层（极低/极高误差）造成分配偏差。

**证据/说明**：adaq_precompute.py 的迭代水位法保证截断后总秩守恒。截断后的重新归一化在脚本中已实现。
